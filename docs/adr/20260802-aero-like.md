# Capability ADR — Aero-like lift/drag

## Status

Accepted / Implemented

## Goal

Apply simple lift/drag forces on bones tagged with `aeroArea` so flight-task airtime/altitude can improve.

## Rapier design

- Optional `BoneDef.aeroArea` (world-unit² scale, authored)
- Each physics step: approximate drag opposite velocity; lift perpendicular to velocity in 2D (upward bias when moving)
- Coefficients in `physics/constants.ts`: `AERO_DRAG_COEFF`, `AERO_LIFT_COEFF`
- Applied via `addForce` after muscles, before `world.step()`, equal treatment with force reset

## Explicit non-goals

- No parachute deploy / packed state machine (structural parachute parts are a separate ADR)
- Do **not** step physics with variable/render dt

## Smoke gate

`scripts/smoke-tasks.mts` — body with aeroArea falls slower than identical body without.

## Rollback

`featureFlags.aeroLikeForces`; ignore `aeroArea` when flag off / task ≠ flight.
